Your Claude Code harness, measured

A harness — CLAUDE.md, rules, skills, hooks, agents, MCP servers, a knowledge base — decides what a Claude Code session costs and delivers, yet it is tuned as a black box. Log Hub shows what each part does. With the same model, the harness alone changes the cost per task up to five times at similar success rates (UC Berkeley and Arena, 2026).

What Log Hub answers

  1. 01 · costWhere the money goes: per session, branch, skill and tool, with budgets and a forecast.
  2. 02 · speedHow long the agent worked alone, and where the time went.
  3. 03 · contextWhat your harness loads into every session, and what the agent actually uses.
  4. 04 · qualityWhich of your checks ran in a session, and with what result.
  5. 05 · teamTrends, reports and anomalies across every session and developer.
  6. 06 · toolsWhich MCP servers and CLI tools work, fail or are never called.
  7. 07 · safetyWhat the agent read, ran and sent — traceable afterwards.
  8. 08 · trustLog Hub's own data: what is collected, who can see it, how long it is kept.

How it runs

  • Self-hostedRuns on your own server with Docker and PostgreSQL.
  • Data stays on your hostSession data is stored in your own database; there is no hosted service.
  • Network-isolatedWorks with no internet access: the app, its help and its docs ship together.
