For engineering and security leads

Questions you will ask

Straight answers about where the data goes, who can read it and what Log Hub does not do. Each answer links to the document that has the details.

Data and where it goes

Where does the data go? Does DataArt see any of it?
To a server you run — on one machine, on your LAN or behind your VPN. DataArt runs no hosted service and receives nothing. Sessions are stored in your Postgres. Install the server
What exactly does the hook collect?
The full Claude Code transcript, unredacted by design: prompts, tool results, file contents Claude read and command output. Plus CLAUDE.md, rules, skills, MCP configuration and the git remote (credentials stripped), branch and git user. Plus Claude Code's OpenTelemetry data (cost, tokens and calls per model and call source), a snapshot of each OKF knowledge base in the repository (file paths, sizes and hashes, no content) and the input and output of the command-line tools you choose to monitor (up to 100 KB per stream). The installer shows this notice before it installs. Data collection & upload
Can we keep secrets or sensitive files out?
Yes, at the source: Claude Code permissions.deny rules keep files out of what Claude can read, so they never reach a transcript. The hook itself does not redact. Security hardening
Does anything you add call out to the internet or to the model provider?
The server makes three public GET checks and sends no data with them: the Claude Code version list from npm (hourly, AI_TOOL_VERSION_CHECK_ENABLED), the model price list (daily, MODEL_PRICING_FETCH_ENABLED) and the latest Log Hub release from GitHub (daily, official release images only, LOG_HUB_RELEASE_CHECK_ENABLED). Set any of them to false to turn it off. The optional post-turn analysis (cost advisor, session attribution) runs claude -p on the developer's machine through the same Claude connection the session already uses, and is switched per repository. Since hook 2.31.1 that claude -p runs with no tools, no MCP servers and no skills on a current Claude Code, so it can only answer — it cannot read files, run commands or call an MCP server. Keep Claude Code current: a version too old for those flags runs it without them. Server settings
Does it work in an air-gapped network?
Yes. The app, its in-app help and every user document ship with the product; with the three checks turned off nothing leaves the host.

Access

Who can read my engineers' prompts?
In a restricted team (the default) members see only their own sessions, the team owner and ADLC trainers see prompts, managers see analytics without prompt text. A transparent team is opt-in. The admin role grants no access to session data. A member becomes visible to the team only after accepting a disclosure notice. Data collection notice
Which sign-in methods are there? SSO?
Identify by email, email and password (optionally with email confirmation), or Microsoft Entra ID, single tenant. Other identity providers are not supported today. Authentication modes
Is there an audit trail?
Security events — sign-ins and their failures, sign-up, email confirmation, password reset and change, account deletion — are logged as structured lines with email and user ID only. There is no log of who opened which session. Security hardening

Storage and retention

How long is data kept?
The server deletes sessions older than SESSION_RETENTION_DAYS (default 30) — set it to your policy. Deleting an account is a hard delete of the user and all of their data. The server's own log files are kept for 5 days (SQL logs 3 days, 100 MB in total) by default — see LOG_RETENTION_DAYS, SQL_LOG_RETENTION_DAYS and LOG_RETENTION_MAX_MB.
We have record-keeping obligations. Does Log Hub cover them?
No. Log Hub has no immutable (WORM) storage; long-term retention belongs to your backup layer.
Encryption at rest and in transit?
At rest: the app does not encrypt the database itself — use host or volume encryption. In transit: terminate TLS at your proxy and give developers an https:// server URL.

Scope

Does it stop anything?
No. The hook only observes; it never blocks a tool call. Prevention stays in Claude Code permissions. A budget is a reference amount too: crossing it sends a notice, never a stop. Budgets
Which assistants are supported?
Claude Code.
What runs on developer machines?
The hook: plain, readable Node.js scripts with no third-party dependencies, installed with npx from your own server. New servers keep accepting uploads from older hooks. How the hook works
