# PowerShell tool monitoring respects your permission rules on Claude Code 2.1.326

- The hook (2.32.2) now records PowerShell calls of monitored tools only in bypass-permissions mode; in every other mode the command runs exactly as typed, so allow and deny rules work as without the hook, and `hook.log` notes once per session why a call was left unrecorded.
- An empty native stderr line in a recorded PowerShell call stays empty instead of showing the `RemoteException` type name.
- The Monitored Tools settings show "hook too old — update the hook" for a Windows hook older than 2.32.2.
