# Log Hub site, "Why Log Hub" deck and shared user docs

- New static site (Home, Features, Questions, full user docs) and a "Why Log Hub" deck, published to GitHub Pages, in an "old digital" look with real screens of the app.
- The Home example walks one session from where the money went, through how the harness worked and how it compares with the team, to what to do about it; the deck adds chart mosaics, where the data flows and what is collected, who reads it and how long it stays.
- The in-app help and the site now share one page set: new pages for installing the server, authentication modes, server settings and the trust model; help links between pages, to headings and to external sites work. On the site the architecture diagram is drawn, not ASCII.
- The README is shorter: a pitch, a minimal quick start and links to the docs, site and deck.
