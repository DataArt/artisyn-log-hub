# "Why was this session expensive?" opens the session; deep-linked sessions are selected

- The Home / All views question "Why was this session expensive?" now opens your latest session of
  the repository under the Cost lens (Statistics) instead of the repository's cost analytics.
- A session opened by a link is now selected and scrolled into view in the session list in every
  list mode (by date, by user, by branch), its group opened automatically.
- The top bar shows the release version (e.g. `v1.3.0`) for an official release instead of the commit.
