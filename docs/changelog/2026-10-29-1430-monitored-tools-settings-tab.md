# Monitored tools moved to repository settings

- The monitored-tools list is now edited on its own "Monitored Tools" tab of the repository
  settings instead of a dialog; the "Monitored tools (N)" button on the Tools/MCP tab opens that tab.
- The unreliable "Fell back to search" signal is gone from the Tools/MCP tab; existing tool usage is
  rebuilt without it in the background.
- Picking another tool or operation in the Tools/MCP tree clears the call details pane.
