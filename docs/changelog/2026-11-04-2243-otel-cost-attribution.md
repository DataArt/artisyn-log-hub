# OTEL cost attribution by skill, MCP server, effort and plan

- The OTEL tabs (repository, session, team) can group cost by skill, MCP server, effort and fast mode; calls without the attribute show as "not reported".
- The session OTEL tab shows the Claude account (plan, seat, provider) with a plan chip, and the repository and team tabs show the mix of plans.
- Sub-agent cost for sessions from older Claude Code versions now uses the OTEL cost when it is higher than the transcript estimate, marked "from OTEL".
