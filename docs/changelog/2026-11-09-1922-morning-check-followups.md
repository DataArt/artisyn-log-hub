# Background MCP calls show their real result

- MCP calls that Claude Code moves to the background now show the task's real result, status and duration once its notification arrives; a call whose result never reached the log shows "no result" instead of the hand-off text. The hook (2.31.2) counts them the same way in its post-turn evaluation.
- The hooks installer warns when Node.js is past end of life.
- The nightly security scans retry their tool downloads.
