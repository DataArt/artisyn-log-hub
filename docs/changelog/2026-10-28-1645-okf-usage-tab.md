# OKF knowledge-base usage tab

- New "OKF" tab on a session and on a repository shows how Claude used the repo's OKF knowledge
  base: which KB files were read, grepped or listed, by which agents, and a verdict with the reasons.
- The hook (2.26.0) sends a snapshot of the repo's KB bundles; the new `okf.exclude` hook setting
  leaves folders out. Older hooks keep working without the snapshot.
