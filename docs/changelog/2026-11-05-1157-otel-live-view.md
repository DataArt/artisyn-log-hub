# OTEL Live view

- A "Live" item in the top bar shows whether any Claude Code session is sending telemetry right now and opens a live view of the last 2 hours.
- The live view has a tree of teams, repositories, users, sessions and agents with live cost, rows that flash when cost grows and greyed-out sessions that have stopped.
- For the selected node it shows charts of cost, tokens and calls over time, a breakdown table and a cost flow (or token flow for a session) from models to teams, users, repositories, sessions and agents.
