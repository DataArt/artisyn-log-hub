# Budgets, spend forecasts and cost slices

- Daily, weekly or monthly spend budgets for a personal repository, a team repository or a whole team, set in Settings › Budgets (team page: Settings tab) with an event log; budgets are reference only and never stop usage.
- A new Spend tab shows the spend against the budget with burn rate, forecast and "runs out in", daily spend with anomaly days, cost slices by model, user, repository, branch, sub-agent, skill and MCP server, and costly sessions.
- A 5-minute job raises threshold notices in the bell and a banner, and by email when SMTP is configured (`BUDGET_CHECK_INTERVAL_MS`, `BUDGET_CHECK_ENABLED`).
- Analytics gets a Budget Burn view and Reports a Budget report; a new Budgets help page explains it all.
