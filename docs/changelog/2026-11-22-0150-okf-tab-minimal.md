# OKF tab cut down to four clear views

The repository and session OKF tabs now show the same simple page: a summary line (how many
sessions or agents read the KB, about how many tokens and dollars of context that was), the format
version of each KB folder, the articles with a wrong format, the most-read files, and an explorer
of every KB file that marks the ones never opened.

- The verdict card, KPI tiles, value signals, agent trail, article drill-down and the Bytes/Calls
  switch are gone, and so is the "OKF thresholds" section of the repository settings.
- A new estimate shows what the KB reads cost and their share of the total spend of the same
  sessions.
