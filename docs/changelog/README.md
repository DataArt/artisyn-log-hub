# Changelog

One short file per finished change: `<YYYY-MM-DD-HHmm>-<task-slug>.md`, a one-sentence (or few-bullet)
summary of what changed in the application. Written before the change is pushed — see the
`changelog` skill (`.claude/skills/changelog/SKILL.md`). Every GitHub Release attaches a
`CHANGES.md` built from the entries added since the previous release (newest first).
