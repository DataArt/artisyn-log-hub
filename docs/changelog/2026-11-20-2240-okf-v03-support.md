# OKF v0.3 support in the OKF tab

- Hook 3.1.0 reads OKF front matter from the first 8 KB of a file and sends the bundle's title, description and declared format version plus per-article metadata.
- The OKF tab shows bundle titles, an "OKF x.y" chip and sky advice hints (newer format available, articles that can be improved), and amber "deprecated → replacement" and "past stale_after" chips in the tree and the agent trail.
- Code-path pointers in articles resolve the OKF v0.3 way (`./` and `../` relative to the article, `/x` relative to the bundle root); nested `index.md` / `log.md` files and dot-path files no longer count as articles. Recompute sessions to re-extract older sessions.
- A session whose own upload failed and was re-uploaded later by another session now gets its KB snapshot too (it used to show as "without a snapshot"), and its KB reads are recomputed against it; broken front-matter values such as `title: [unclosed` are ignored instead of shown.
- Older hooks keep working; their data renders exactly as before.
