# Shell tab: PowerShell calls next to Bash

- The session Bash tab is now **Shell**: PowerShell calls appear in one chronological list with Bash calls, with a shell filter and `bash` / `pwsh` badges on mixed sessions.
- PowerShell commands get the same formatted view as Bash: layout, highlighting, working dir, FILES summary (deleted files are marked) and the "changes N" chip.
- Commit / PR counters and OKF knowledge-base reads now count PowerShell calls too; already stored sessions are updated in the background.
