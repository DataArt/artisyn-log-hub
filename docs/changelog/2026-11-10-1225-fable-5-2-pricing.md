# Claude Fable 5.2 pricing

- Sessions on Claude Fable 5.2 (the default Fable model since Claude Code 2.1.321) and Claude Mythos 5.2 now show their cost: $8 / $40 per million tokens, 1M context. Before, they showed "unknown model" and no cost on installations without the daily price fetch. A price that an admin or the price fetch has already set for these models is kept.
