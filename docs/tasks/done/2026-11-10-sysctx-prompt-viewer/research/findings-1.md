# Research findings 1 — 2026-11-11

## Requirements summary
Client-only feature (GH-123): on the **System context anatomy** tab (`sysctx`) add a **"View system prompt"** button, shown only when the main transcript has ≥1 `prompt_snapshot` attachment (no disabled state). It opens a lazy-loaded modal with three accordion tabs: **System prompt** (startup snapshot's `systemPrompt[]` parts, each titled by first Markdown heading or first words + size; `__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__` is not an item but splits the list into Shared / Session-specific groups), **Tool definitions** (from the first snapshot with non-empty `tools` — usually the one after the first assistant reply; summary line + one item per tool with description as Markdown and schema as JSON), **Flags** (every top-level key except `systemPrompt`, `tools`, `rendered`). Markdown is rendered with `react-markdown`+`remark-gfm`, raw HTML as text; items collapsed by default; Expand all / Collapse all per tab; header totals; "Copy as Markdown" + "Download .md" export of the whole view built in-browser. Absolute local paths are masked once on the parsed model (modal and export identical). Sizes UTF-8 bytes, tokens = bytes / `resolveCharsPerToken`. Old sessions without a snapshot unchanged; malformed snapshot never breaks the modal. Parsing/grouping/sizing/snapshot selection/masking in one pure module with a new algorithm doc + rows file + `*.algo.test.ts`; a scenario step in `s-sess-03` with GS-05 extended.

## Open gaps
1. Snapshot outside the startup block: FR-1 shows the button for any `prompt_snapshot` in `main`, FR-6 takes prompt/flags from "the startup snapshot" — undefined whether that is the first of the startup block (rule 9) or the first non-sidechain anywhere; what the modal does if the only snapshot is after the anchor; whether `isSidechain` lines are skipped.
2. Shared helpers (`blockText`, `utf8`, `displayPathOf`, anchor finder) are private in `sysctx-anatomy.ts` — export them or build a small shared util; no twins.
3. Masking algorithm is new: `displayPathOf` works on whole paths only, `toUserDisplayPath` does not replace `projects/<slug>`, no in-text path regex exists. Decide the regex (drive `X:\`/`X:/`; `/Users|home|tmp|var|opt|mnt/`; terminators), repoRoot with spaces, order (repoRoot → `/.claude/` → `<outside>`), walking schema objects (string values only), flag values. `KNOWN_TOP_LEVEL_DIRS` fallback without repoRoot is not mentioned in the NFR.
4. No accordion component: items on `ui/collapsible.tsx` or plain button + conditional render (body mounts only when expanded). Whether the Flags tab has Expand/Collapse all.
5. Modal tab state: local (as `WorkflowAgentModal`) or URL param — rule says page/panel tabs in URL; no precedent for modal tabs.
6. Lazy loading: modal can join `session-tabs-lazy-group.ts` (already lazy with the anatomy tab); separate `import()` would make 10 targets (the max); `react-markdown` already eager; "parses only when opened" still needs a cheap `hasSnapshot` check in the tab.
7. Display format: tool size unit (B vs KB), share precision, ≈ tok on tool rows.
8. Export details: filename (e.g. `system-prompt-<sessionId>.md`), export text with tools absent/malformed, group headings, tool order.
9. Clipboard in scenarios: no precedent — `grantPermissions(['clipboard-read','clipboard-write'])` or a `navigator.clipboard` stub via `addInitScript`; `s-sess-03` runs in modes A and C.
