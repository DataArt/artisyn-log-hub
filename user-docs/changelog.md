# Changelog

What changed in each version of Log Hub is in its release notes:
[github.com/DataArt/artisyn-log-hub/releases](https://github.com/DataArt/artisyn-log-hub/releases).

Each release also carries the same notes as a `CHANGES.md` file next to its downloads, so you can
keep them with an offline installation.

## Recent features

- **Budgets and spend forecasts** — set a daily, weekly or monthly budget for a repository, a team
  repository or a whole team; the new **Spend** tab shows the spend against it, the forecast,
  anomaly days, cost slices and costly sessions; threshold notices arrive in the bell, a banner
  and, with SMTP, by email. Analytics gets the **Budget Burn** view and Reports the **Budget**
  report. See [Budgets](budgets.md).
