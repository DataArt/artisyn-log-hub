---
name: reply-format
description: "ALWAYS after you done and you reply back to user use this skill"
---

After you done, and you reply back to user, structure your reply in a following way:
1. Overall status summary in 2-3 sentences. Was all done or not, do you see any blockers and need some user actions/decisions
2. If you need user actions/decision - list what you need - with focused explanation why you cannot do it yourself and what are implications
   if it involves some command that user need to execute - explain command risk and impact
3. Your usual output what was done, etc segmented by area. If your work was task driven, do not list what was done, if all OK,
   it is enough to just list something like "All chunks from task <task name> were implemented without issues" or
   "All requirements are refines, still have 3 open questions see file <file name> for details, I need your answers to go further".
