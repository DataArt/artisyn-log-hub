# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues, discussions or pull requests.

Report them to DataArt through the vulnerability disclosure process:

- **Contact:** https://www.dataart.com/vulnerability-disclosure#report
- **Policy:** https://www.dataart.com/vulnerability-disclosure
- **Preferred language:** English

You can equally report a vulnerability privately through GitHub private vulnerability reporting:
open this repository's **Security** tab and click **"Report a vulnerability"**. Both channels are
equally valid; use whichever is more convenient.

DataArt's machine-readable security contact is published at
https://www.dataart.com/.well-known/security.txt.
